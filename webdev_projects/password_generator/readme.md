Project idea and instructions can be found at [app.bigdevsoon.me/challenges/password-generator](https://app.bigdevsoon.me/challenges/password-generator/)

## User story

As a user i need a simple interface to generate strong passwords. I look for several important features. First i want to see the generated password in the output field. I need few buttons that will copy the password string or randomize it and generate new string.

Below the output i will have settings fields. Slider to select the output length and the following toggles: Uppercase letters, lowercase letters, numbers, symbols.
